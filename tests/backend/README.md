# Validação do backend

Testes `pytest` do pacote `visiondoc`, com arquivos sintéticos gerados por `sintetico.py`. Testes que dependem dos modelos (extra `modelos`) são pulados quando eles não estão instalados. Planejar casos a partir de critérios de aceitação; usar documentos sintéticos ou dados formalmente autorizados. Incluir falhas, entradas malformadas, limites e conteúdo adversarial sem executar conteúdo recebido.
