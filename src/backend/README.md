# Backend

Código do pipeline da [especificação 001](../../specs/001-pipeline-documental-seguro/spec.md), no pacote `visiondoc`. Implementadas as tarefas T024 a T030 (base, ingestão, pré-processamento, transcrição, detecção, mascaramento e `alertas.csv`). Ambiente e testes: `uv sync` e `uv run pytest`.

Antes de adicionar código, vincule a mudança a uma especificação SDD aprovada em `specs/`, com contratos, validação, comportamento de erro e controles de segurança/privacidade definidos.
