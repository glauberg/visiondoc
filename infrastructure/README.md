# Infraestrutura

Área reservada à documentação de ambientes, implantação, observabilidade, continuidade e operação. Não há infraestrutura definida neste estágio. A única exceção executável é [`poc-t020/`](poc-t020/README.md), prova de conceito descartável da inferência do VLM (T020), que não faz parte do pipeline.

Antes de qualquer implantação, especificar fronteiras de confiança, tratamento de documentos, localização dos dados, isolamento, controle de acesso, gestão de segredos, retenção, recuperação e resposta a incidentes.
